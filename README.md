## Что это

Вы ставите цели, планируете задачи и привычки, отмечаете прогресс — приложение
строит прогноз достижения с доверительным интервалом и показывает, опережаете
вы график или отстаёте.

Работает офлайн. Аккаунт не нужен. База SQLite живёт в вашем браузере или на
вашем компьютере, а не на нашем сервере.

## Как установить

| Где | Как |
|---|---|
| Браузер | [thedad.ru](https://thedad.ru) — можно установить как приложение (значок в адресной строке) |
| Windows | `THEDAD Setup x.y.z.exe` из [последнего релиза](https://github.com/uyellowline/thedad-releases/releases/latest). Есть portable-версия без установки |
| Chrome | `planer-extension.zip` из релиза → `chrome://extensions` → Режим разработчика → Загрузить распакованное |

Контрольные суммы файлов — в `SHA256SUMS-extension.txt` рядом со сборками.

## Резервные копии

Приложение само хранит несколько последних снимков базы и предлагает выгрузить
её в файл. Дополнительно можно включить копию в ваш Google Диск: она шифруется
на устройстве вашей парольной фразой, ложится в скрытую папку приложения и
недоступна ни Google, ни нам. Потеря парольной фразы означает потерю копии.

## Что здесь лежит

Только готовые сборки, история изменений и обсуждение проблем. Исходный код
живёт в отдельном репозитории.
